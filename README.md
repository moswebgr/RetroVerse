# RetroVerse

A static retro-gaming discovery UI inspired by the dark, cinematic feel of cloud-gaming libraries.

## Run locally

Open `index.html` in a browser. No build step or backend is required.

## Deploy with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. GitHub Pages will publish the site at the repository's Pages URL.

## Current prototype

- Responsive landing page and navigation
- Platform browsing and game search
- Featured game cards and game details modal
- Favorites (kept in page memory for this UI prototype)

## Next steps

Connect a browser emulator and a catalog of legally distributable homebrew, public-domain, or licensed game files. The current game cards are UI/demo entries; game playback is not wired up yet.
