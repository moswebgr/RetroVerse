# RetroVerse

RetroVerse is a curated retro-game catalog focused on homebrew and freely distributable games.

## Security and file policy

- There is no public ROM upload feature or user-submitted file storage.
- The website does not accept ROM files from visitors.
- Games are maintained by the site owner in the catalog.
- Only add games and game assets that are authorized for redistribution.
- The player loads catalog game URLs; it does not provide a visitor file picker.

The site is currently published as a static GitHub Pages website.
